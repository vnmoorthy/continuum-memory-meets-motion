## Script

### 0:00 — Hook
“This is **Continuum** — the **Open Loop OS**. Memory that doesn’t just recall… it **burns unfinished work**.”

### 0:20 — Problem
“Every team accrues **Open Loop Debt**: meetings, promises, renewals. Chatbots summarize it. Agents sometimes act. Almost nothing **measures** that debt or **closes** it with durable memory.”

### 0:45 — Product
“Continuum stores organizational memory as a graph, scores open loops by priority × age × dollars at risk, then runs **Cited Motion** pipelines that write results back — so debt goes down.”

### 1:05 — Live demo (primary)
1. `/` — Continuum full-bleed hero (brand first).  
2. `/app` — Open Loop Debt score + **$ at risk** (Acme **$220k**).  
3. Click **Close My Morning**.  
4. `/app/runs` — retrieve → reason → cited artifact → write-back.  
5. Scroll to **## Citations** — grounded in memory nodes.  
6. Show debt **before → after**.  

Optional: Settings → sponsor status, or Watchdogs **Scan now**.

### 2:20 — Architecture
“FalkorDB graph mirror. RocketRide pipelines. Linkup research. LaserData events. Guild experiments. Snyk scans. Demo mode stays honest without keys.”

### 2:45 — Close
“Continuum isn’t another chatbot — it’s the substrate that makes Memory meet Motion. **Close the loop.**”
